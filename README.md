# 📻 业余无线电考试刷题系统

一个纯前端、无服务器的个人刷题工具，支持顺序练习、模拟考试、错题本、收藏与统计。

## ✨ 功能特点
- 📖 **刷题练习**：支持顺序/随机模式
- 📝 **模拟考试**：智能组卷，60分钟计时
- ⭐ **收藏与错题**：自动记录，针对性复习
- 📊 **学习统计**：正确率、连续学习天数
- 🌙 **深色模式**：自动适配系统主题

## 🚀 如何使用
- 直接下载 `exam-mobile.html`，双击在浏览器中打开即可，支持上传 `.md` / `.txt` / `.json` 题库。
- 适配安卓手机，下载到存储空间后，使用浏览器打开，加载题库即可。
